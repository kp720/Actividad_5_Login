## Equipo 9

 Descripción Breve del Proyecto
Este proyecto consiste en una aplicación web interactiva que simula un panel de administración escolar (Admin Panel). Cuenta con controles seguros para la captura de usuarios mediante validación de credenciales y un sistema de gestión de alumnos con reglas estrictas de ingreso para números de control de 8 dígitos y verificación visual de mayoría de edad.
